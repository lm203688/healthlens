# 诊断框架（Diagnostic Framework）

本文件描述 HealthLens 使用的**体检报告诊断框架**：风险分层、置信度体系、双通道输出与阈值来源。框架设计目标是让非技术用户也能理解"为什么这样判"，同时保证临床侧的一致性。

> 术语与代码字段对照见 [`CONCEPTS.md`](./CONCEPTS.md)。

---

## 1. 风险分层（四象限）

体检解读结果按"异常方向 × 严重度"分为四个象限：

| 象限 | 中文标签 | 触发条件 | 用户提示口径 |
|------|----------|----------|--------------|
| 象限 I | 正常 / 低风险 | 指标在参考范围内 | "此项在正常范围内，继续保持" |
| 象限 II | 轻度异常 | 超参考范围但未达临床显著 | "轻度偏离，建议复查" |
| 象限 III | 中度异常 | 达临床显著范围 | "中度偏离，建议专科咨询" |
| 象限 IV | 重度异常 / 优先关注 | 达危急值或多项联动异常 | "高度异常，请尽快就医" |

- **阈值来源**：由参考范围（`reference_range`）与医学事实库（`medical_facts.json`）中的临床显著阈值共同决定，参见 `backend/src/services/report_generator.py` 中的分档逻辑。
- **联动规则**：单项达 IV 象限，或两项以上 II/III 象限相互印证时，整体结论上调一级（例：LDL-C ↑ + 总胆固醇 ↑ → 心血管风险升级）。

---

## 2. 置信度体系（三档）

每次给出结论时都会附带一个置信度档位：

| 档位 | 标签 | 含义 | 典型场景 |
|------|------|------|----------|
| `high` | 高置信 | 有明确参考范围 + 有循证医学事实支撑 | 血糖、血脂、尿酸、肝肾功能常见项 |
| `medium` | 中置信 | 有参考范围但缺乏强证据，或需要结合上下文 | 炎症指标、激素单项、部分影像学结论 |
| `low` | 低置信 | 缺少参考范围，或仅凭知识库推理 | 罕见项、报告 OCR 识别存疑、多指标推断 |

**降级触发条件**（自动降一档）：
1. 缺少该指标的 `reference_range`；
2. 该指标在 `medical_facts.json` 中无对应条目；
3. 报告来源为图片且 OCR 置信度低。

---

## 3. 双通道输出

解读结果由两条并行通道产出，避免单一来源的偏差：

- **规则通道**：由 `report_parser.py` + `report_generator.py` 基于参考范围和阈值规则直接判定，覆盖 30+ 常见体检项。
- **知识通道**：由健康咨询 Agent（ReAct 循环）调用 `lookup_medical_facts` / `get_encyclopedia` / `retrieve_guideline` 检索医学事实、百科与指南，产出解释性叙述。

两条通道的结果在 `health_profile.py` 中合并：
- 若两者一致 → 置信度保持；
- 若冲突 → 以规则通道为准，并在 `source` 字段中标注知识通道证据链，同时降一档置信度；
- 若规则通道无法覆盖（罕见项）→ 仅输出知识通道结果，置信度上限为 `medium`。

---

## 4. 输出结构

`HealthProfile` 是解读结果的核心结构（定义见 `backend/src/models/report_schema.py`）：

```json
{
  "profile_id": "...",
  "generated_at": "ISO-8601",
  "source": "text" | "image",
  "abnormal_items": [ { "name": "...", "value": 0.0, "unit": "...", "reference_range": "...", "quadrant": "II", "confidence": "high" } ],
  "normal_items":   [ { "name": "...", "value": 0.0, "unit": "...", "reference_range": "..." } ],
  "covered_metrics": ["ALT", "AST", ...],
  "knowledge_cards": [ { "metric": "...", "facts": [...], "guidelines": [...] } ],
  "summary": "自然语言摘要",
  "follow_up": { ... }
}
```

---

## 5. 免责声明

本框架输出仅供健康参考，不用于临床诊断或治疗决策。任何结论都应结合用户实际病史、当前用药情况与专业医生意见综合判断。
