## 1. 研究背景与意义（Summary for IRB）

### 1.1 问题陈述

现有 wellness 干预研究普遍缺失三件事：
1. **个体异质性**——群体 RCT 的平均效应无法预测"张三"这个人的收益；
2. **可测量的稳态轴**——干预的下游信号（睡眠/血糖/炎症/自主神经/HPA/线粒体/肾精…）缺乏统一维度；
3. **可复用的因果装置**——n-of-1 crossover 与贝叶斯聚合缺乏可开源的实现。

HealthLens 已交付八轴稳态框架（A–H）与 L1 层 `app/lib/nof_one_effect.py`（个体效应量 + 层次聚合），
本次前瞻队列是把这套装置放到真实数据上做的第一次外部有效性检验。

### 1.2 研究意义

- **科学层**：验证八轴作为 wellness 稳态表征在真实干预下是否可重复；为耦合系数矩阵提供后验标定数据。
- **方法学层**：为 wellness 领域的 n-of-1 crossover 与联邦聚合提供可复用的开源栈。
- **平台层**：为 HealthLens 提供外部有效性证据，是"方法学论文 → 平台论文"的必要跳跃。

## 2. 研究设计（IRB 关注点）

### 2.1 研究类型

- **观察性研究**：n-of-1 crossover wellness 追踪
- **无干预变量**：所有"干预"由参与者自主决定，HealthLens 仅提供提示与引导
- **无对照组的强制分配**：所有参与者均为 self-selected 用户，接受平台服务的公开订阅

### 2.2 参与人员

- 招募目标：30–60 人（受 IRB 建议调整）
- 招募周期：8–12 周
- 数据来源：**仅平台匿名聚合 telemetry + 用户主动上报的公开数据**（如 Fitbit/Apple Health 的聚合摘要）

### 2.3 时间线

- 阶段 1（方案定稿）：4 周
- 阶段 2（IRB 审查）：2–3 周
- 阶段 3（数据收集）：8–12 周
- 阶段 4（分析 + 论文撰写）：6–8 周

## 3. 风险-收益评估（CIOMS 2016 §1.1）

### 3.1 潜在风险

| 风险类别 | 具体描述 | 缓解措施 |
|---|---|---|
| 隐私风险 | 参与者的健康数据被识别 | 去标识化 + GDPR 最小必要原则 |
| 数据泄露 | 传输/存储中数据暴露 | AES-256 加密 + TLS 1.3 + 访问日志审计 |
| 心理风险 | 参与者看到异常数据产生焦虑 | 明确「非诊断」声明 + 提供心理支持渠道 |
| 商业利用 | 数据被用于商业目的 | 数据契约禁止 + 独立第三方审计 |
| 误诊误治 | 用户误把 wellness 建议当作诊断 | 全链路合规护栏 + 「非医疗」免责声明 |

### 3.2 潜在收益

| 收益类别 | 具体描述 |
|---|---|
| 科学收益 | 首次提供 wellness 领域 n-of-1 crossover 的可复用开源栈 |
| 个体收益 | 参与者获得自己的健康数据全景与趋势分析 |
| 社会收益 | 为 wellness 平台的方法学论文提供外部有效性证据 |

### 3.3 风险收益比

本研究的风险显著低于干预性研究（无强制干预、无生物采样、无诊断），
同时为 wellness 领域的方法学进步提供关键证据——风险收益比可接受。

## 5. 数据治理与隐私保护

### 5.1 数据分类

- **PII**（个人身份信息）：姓名、邮箱、电话——**不采集**
- **PHI**（健康信息）：睡眠、活动、心率——**去标识化后采集**
- **研究数据**：HealthLens 计算的 wellness 指标——**仅研究用途**

### 5.2 去标识化流程

- 移除所有直接标识符（姓名、邮箱、IP 等）
- 对聚合数据应用 k-anonymity（k≥5）
- 使用稳定 hash（如 SHA-256）替换原始 ID
- 保留最小必要字段用于研究分析

### 5.3 数据存储与访问

- 存储：加密数据库（AES-256）+ 只读备份
- 访问：最小权限原则 + 审计日志
- 删除：参与者申请删除时 30 天内完成

### 5.4 数据契约

- 数据仅用于本研究，不转让、不出售
- 不与其他数据集合并用于商业目的
- 研究结束后 5 年删除（或永久删除）

详见 `docs/prospective_cohort/data_governance.md`。

## 6. 数据安全性与质量控制

### 6.1 数据安全

- 传输：TLS 1.3 + 证书固定（certificate pinning）
- 存储：AES-256-GCM 加密
- 访问：JWT 短期令牌 + MFA + IP 白名单
- 审计：所有数据访问记录到不可篡改日志

### 6.2 质量控制

- 双人录入：所有参与者数据需二次核对
- 缺失数据规则：缺失率 >30% 的数据集不入组
- 异常值：使用 IQR 方法标记，不删除
- 数据冻结：研究中期（第 6 周）冻结数据，避免「分析-修改」循环

### 6.3 数据可用性

- 原始数据（去标识化）：仅 IRB 批准后向合作研究者提供
- 分析代码：开源在 HealthLens 仓库
- 分析报告：预印本 + 期刊投稿

## 7. 利益冲突声明

### 7.1 研究者利益

- 研究者是 HealthLens 平台的开发者/贡献者
- 研究者持有 HealthLens 的股权/期权（占位 `[待填]`）
- 研究者可能从本研究获得直接或间接利益

### 7.2 利益冲突缓解

- 独立第三方审稿（IRB 成员不包含研究者）
- 研究协议预先注册（OSF）
- 分析代码开源，结果可独立复现
- 期刊投稿时向编辑披露所有利益冲突

### 7.3 商业利益

- HealthLens 平台可能因本研究推广而获得商业利益
- 本研究数据不用于商业营销
- 研究结果不用于产品宣传
