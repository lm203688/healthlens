## 一、一句话概述

HealthLens 把**现代医学的稳态生物学（自噬、线粒体、昼夜节律、炎症、表观遗传）**与**中医的整体观（八轴体质辨识）**映射到同一套"八轴稳态模型"，再用**可解释的融合引擎**把基因/组学弱项、中医古籍经验、循证风险模型编织成**去医疗化的个性化养生调理方案**，并坚持"急症红牌拦截 + 用药术语屏蔽 + 数据脱敏"三重安全护栏。

## 二、核心理念：整合医学「八轴稳态模型」

### 2.1 为什么是"八轴"

现代精准健康管理的痛点不是"数据少"，而是**数据异构、无法统一决策**：基因报告讲 SNP、体检报告讲指标、中医讲证型、可穿戴讲睡眠/心率。HealthLens 提出一个统一语义层——**八轴稳态模型**，把上述四类数据投影到 8 个可量化、可干预的"健康维度"上，使西医指标、中医证型、基因弱项能在同一坐标系里相加、相交、排序。

### 2.2 八轴定义与生物医学依据

| 轴 | 名称 | 现代稳态生物学对应 | 中医映射 | 阈值（<0.5=弱项） |
|----|------|-------------------|----------|------------------|
| A | 气化-自噬 | Autophagy（细胞自噬，清除受损蛋白/细胞器，衰老核心机制） | 气化 | 0.5 |
| B | 气血-线粒体 | Mitochondrial / ATP（线粒体产能→组织供能） | 气血 | 0.5 |
| C | 络脉-清瘀 | Senolytics / 微循环（衰老细胞清除、血液流变） | 血瘀/络脉 | 0.5 |
| D | 阴阳-昼夜 | Circadian / BMAL1（昼夜节律生物钟） | 阴阳/睡眠 | 0.5 |
| E | 脏腑-神经内分泌 | HPA 轴（下丘脑-垂体-肾上腺应激轴） | 脏腑 | 0.5 |
| F | 正邪-炎症 | NF-κB / TNF / IL-6（慢性炎症通路） | 正邪/热毒 | 0.5 |
| G | 神-情志 | Serotonin / 神经递质（情绪与肠脑轴） | 神/情志 | 0.5 |
| H | 先天-肾精 | Epigenetic clock / 造血 / 干细胞（表观遗传时钟、sPL） | 肾精/先天 | 0.5 |

> **理论基础说明（诚实标注）**：八轴是"结构化养生映射框架"，将中医概念与现代稳态生物学的对应维度做**可解释挂钩**，用于指导个性化调理建议的生成与排序；它**不是严格的医学同构**，也不构成疾病诊断。轴内阈值、权重集中在 `data/healthlens_config.json` 配置中心，可由领域专家调参，不写死在代码里。

### 2.3 融合评分公式

配置中心定义的融合评分（详见 §5）：

```
fusion_score = gene_score × 0.6 + axis_weight × 0.3 + symptom_weight × 0.1
```

证据分级权重：`L1=1.0 / L2=0.7 / L3=0.4`（来自融合引擎 `EVIDENCE_WEIGHT`，与配置中心 `evidence_weight` 一致，L1=高质量循证、L2=中等、L3=经验/古籍）。

## 四、双轨诊断引擎

### 4.1 西医诊断引擎（规则 + LOINC/ICD-11）

`app/core/diagnosis_engine.py` 实现指标异常→疑似疾病映射：

- 以 **LOINC 编码**为键匹配（血糖 `2345-7`、总胆固醇 `2093-3`、甘油三酯 `2085-9`、ALT `2571-8`、WBC `785-6`、血红蛋白 `718-7`、肌酐 `6299-1`）。
- 异常方向（高/低）命中规则后，输出 **ICD-11 编码 + 严重度（mild/moderate/severe）+ 置信度 + 依据指标 + 复查建议**。
- 规则引擎基础置信度 `0.65`，明确标注"疑似/建议复查"，不做临床确诊。
- 输入来自 OCR 解析的报告（22 种指标自动提取）→ LOINC 标准存储 → 趋势分析。

> **成熟度**：Phase 1 规则引擎，覆盖 7 类核心指标；Phase 2 规划集成医学大模型。

### 4.2 中医辨证引擎（九种体质 + 六证型）

`app/core/tcm_engine.py`：

**① 九种体质辨识（中华中医药学会标准算法）**
- 每体质 5 条目问卷，1–5 分。转化分公式：
  `转化分 = (原始分 − 条目数) / (条目数 × 4) × 100`
- 判定规则：平和质须转化分 > 60 且显著高于其他（>0.7×）才判为主体质；否则取非平和质最高分。
- 九型：平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀，各带特征关键词与判定阈值。

**② AI 辨证（六证型关键词匹配）**
- 气虚/阳虚/阴虚/痰湿/湿热/血瘀，按症状关键词命中数（≥2）判证型，输出治法（补气/温阳/滋阴/化痰祛湿/清热利湿/活血化瘀）+ 置信度（0.5+命中数×0.1，封顶 0.9）。

**③ 经典方剂推荐与加减**
- 内置 6 首经典方（四君子汤、附子理中汤、六味地黄丸、二陈汤、龙胆泻肝汤、血府逐瘀汤），含出处、组成、主治、症状化裁（如"食欲不振→加山药/砂仁"）。

> **成熟度**：体质辨识按学会标准算法（生产就绪级）；辨证为 Phase 1 关键词简化版。

## 五、八轴融合推荐引擎（产品护城河）

`app/lib/fusion_engine.py`（v0.3，确定性 + LLM 增强）：

### 5.1 算法流程

1. **输入**：用户通路级基因/组学得分（0–1，<0.5 视为弱项）、或直接给弱项轴字母（A–H）、个体禁忌。
2. **弱项归一化**：基因 token 经别名表归一化→规范通路→反查所属轴（双保险：通路命中 + 轴字母命中）。
3. **候选匹配**：遍历案例库，计算 `交集重叠度 = 命中通路数 + 命中轴数`。
4. **打分与排序**：
   - 个性化：`score = 重叠度 × 证据权重(EVIDENCE_WEIGHT)`
   - 通用（无交集）：`score = 证据权重 × 0.3`
   - 禁忌命中（用户禁忌关键词出现在案例基因链接/机制里）→ 直接排除。
5. **截断**：取 top-k（默认 8）。
6. **LLM 增强（可选）**：`USE_LLM=1` 时调用本地 Ollama qwen3.8 对处方文本做**个人化、去医疗化语义润色**，失败静默回退规则引擎（永不阻断主流程）。
7. **三态 banner（is_demo 护栏）**：
   - 缺基因数据 → 整批标注"通用健康建议示例，非为你定制"
   - 部分无交集 → 标记"通用建议"，个性化条目标 `personalized`
   - 有基因交集 → 正常个性化输出

### 5.2 输出字段（每条建议）

`case_id / 靶向通路 / 中医来源 / 基因相关性 / 证据等级 / 禁忌 / 监测指标 / 处方 / 模式(personalized|general) / 评分`

### 5.3 案例库与映射

- 案例库 `data/case_evidence_db.json` + 通路映射 `data/tcm_pathway_map.json`（规范通路↔轴、别名回退）。
- 证据分级 L1/L2/L3 在引擎与配置中心双处定义（引擎 `EVIDENCE_WEIGHT={"L1":3,"L2":2,"L3":1}` 用于排序，配置中心 `evidence_weight` 用于展示权重，方向一致）。

> **关键设计**：融合引擎**禁用 SNP 级决定个人方案**（配置 `safety.medical_terminology_blocked` 屏蔽"药量/mg/剂量/处方"等），只用通路级群体证据 → 这是合规与安全的硬性边界。

## 六、慢病风险评估引擎（循证模型）

`app/core/risk_engine.py`，三大模型均注明参考中国权威指南（代码注释核验）：

| 模型 | 依据 | 关键输入 | 输出 |
|------|------|---------|------|
| **ASCVD 10 年风险** | 中国心血管病风险评估和管理指南（China-PAR 简化版） | 年龄/性别/收缩压/总胆固醇/HDL-C/LDL-C/吸烟/糖尿病/家族史/腰围/降压治疗 | 风险等级 low→very_high + 概率% + 分层建议 |
| **2 型糖尿病风险** | 中国糖尿病风险评分（CDRS 简化版） | 年龄/BMI/腰围/收缩压/糖尿病家族史 | 风险等级 + 概率% + 干预建议 |
| **代谢综合征** | 中华医学会糖尿病学分会（CDS）标准 | 腰围/空腹血糖/血压/TG/HDL-C + 用药史 | 符合 ≥3 项即诊断，分级建议 |

- 评分采用**非线性分段映射**（如 ASCVD：score≤3→low，≤6→moderate，≤10→high，>10→very_high），概率随分段递增。
- 总体风险 = 取多项评估中的最高等级与最高概率（`get_overall_risk_level`）。

> **成熟度**：基于指南的**评分简化版**（非完整 Cox 回归系数表）。作为健康风险提示与生活方式干预依据，非临床诊断。

## 八、药物基因组学（PGx）引擎

`app/core/pgx_engine.py`，参考 **CPIC / PharmGKB / FDA 药物基因组学生物标志物表**：

- 覆盖 8 个核心基因：`CYP2D6 / CYP2C19 / CYP2C9 / VKORC1 / DPYD / TPMT / SLCO1B1 / UGT1A1`。
- **基因型→活性评分→表型**：二倍体等位基因活性求和，按区间映射为 PM（差代谢）/ IM（中间）/ NM（正常）/ RM（快速）/ UM（超快）。
- **用药建议规则**：依表型给出"避免/减量/常规/增量"、剂量调整比例、监测要点。涉及可待因、氯吡格雷、华法林、辛伐他汀、伊立替康、硫唑嘌呤等。
- 上下游：`/api/v1/genome/*` 上传与解读；`get_drug_interactions` 汇总非 NM 表型的药物-基因相互作用（PM/UM 标 high 严重度）。

> **成熟度**：规则库完整（Phase 1），但**真实基因数据接入链路**依赖用户上传标准基因型文件或第三方检测对接；当前为规则计算层就绪。

## 九、安全与合规护栏（去医疗化是底线）

配置中心 `safety` 段 + `app/core/desensitize.py` + `healthlens_agent/safety` 三道闸门：

1. **前置红牌（医学急症拦截）**：`red_flag_patterns` 命中（胸痛/呼吸困难/卒中/大出血/意识丧失/抽搐/持续高热等）→ 直接拦截并引导就医，不进入养生建议流。
2. **用药术语屏蔽**：`medical_terminology_blocked` 屏蔽"药量/mg/剂量/处方/用药方案/副作用/禁忌症/停药/换药"等——平台**不提供任何用药处方**，只给生活方式与食养参考。
3. **八轴红线 / 证据断链后置检查**：融合建议经后置闸门，未通过安全闸门的条目在前端标"🚫 需警惕"（见 Dashboard 结果页 `gate_passed` 字段）。
4. **数据脱敏网关**：连接器同步输出经 `mask / pseudonymize / anonymize` 三级脱敏（`desensitize.py`）。
5. **审计与权限**：RBAC 三级（patient/doctor/admin）、JWT+Refresh、认证限流、请求 ID 全链路追踪、PII 字段审计。
6. **统一免责声明**：融合引擎 `disclaimer()` 注入"不构成医疗诊断/处方/治疗建议，基因建议仅基于通路级群体证据，禁单 SNP 决定个人方案"。

> 这是 HealthLens 能在合规边缘稳健运营的核心——把"健康建议"严格框定在**养生/修复参考**内。

## 十三、使用场景与目标用户

### 13.1 典型用户旅程

```
① 注册/登录（邮箱或手机号，首次自动建档）
② 3 分钟自评 / 上传体检报告（OCR）→ 双轨诊断 + 八轴评分
③ 填基因弱项（可选）→ 融合引擎给出个性化养生方案
④ 看古籍食疗/非药物疗法 / 慢病风险分层
⑤ 每日打卡追踪指标趋势 → 仪表盘长期概览
⑥（进阶）对接可穿戴 → 连接器自动同步 → 持续八轴画像
```

### 13.2 目标人群

- **亚健康自查人群**：疲劳/失眠/怕冷/焦虑/消化不良，"想调理但不知从何入手"。
- **慢病风险关注者**：有家族史或指标边缘异常，需要循证分层与生活方式干预建议。
- **中医养生爱好者**：信任古籍经验，但希望与现代稳态生物学挂钩、可解释。
- **基因检测结果持有者**：拿到 23andMe/微基因等报告，想看"通路级弱项怎么落地到生活"。
- **B 端/生态合作**：MCP 工具与 Agent 能力库可嵌入其他健康 Copilot；古籍知识库可作内容源。

### 13.3 明确不做的事（边界）

- 不提供诊断、不开处方、不推荐具体药物剂量。
- 不替代医生；涉及疾病/用药/孕期/特殊体质一律引导就医。
- 基因建议仅通路级群体证据，禁单 SNP 决定个人方案。
