## 二、流程走通性实测

**主链路**：症状 / 舌脉 → 体质辨识 → 证候判定 → 方剂/食疗推荐 → **安全检查** → 输出

| 环节 | 状态 | 判据 |
|---|---|---|
| 体质辨识 | ✅ 通 | `CONSTITUTION_DIMENSIONS` + `TcmDiagnosisEngine` |
| 方剂库 | ✅ 通 | `TCM_FORMULAS` + `_get_formula_library()` + `_get_herb_database()` |
| **配伍禁忌** | ✅ **优秀** | 十八反 / 十九畏，逐对检查，命中即 `has_blocking()` |
| **妊娠禁忌** | ✅ **优秀** | 禁用/慎用分级（高频药节选） |
| **中西药相互作用** | ✅ 存在 | `classify_drug()`；注释标明源自"公开药学资料" |
| 别名归一 | ✅ 好 | `norm()` + `_load_chp_classic_aliases()`，把 CHP 实体别名并入 `HERB_SYNONYMS` |
| 食疗 | ✅ 通 | 459 行，含 `classify_food()` |
| **GB/T 20348-2026 术语对齐** | ❌ **未见** | 无标准术语映射层 |

**评价**：**安全层（436 行）是整个中医板块最有价值的部分**——十八反十九畏 + 妊娠禁忌 + 中西药互作 + 别名归一，这是需要领域知识沉淀的工程化资产，恰恰是研究认定的**行业空白**（"辨证+方剂已高度拥挤，空白在配伍安全/中西药相互作用的工程化闭环"）。

## 三、是否符合人类使用习惯

| 维度 | 评价 | 说明 |
|---|---|---|
| 体质问卷长度 | ⚠️ 待确认 | 标准体质问卷较长，是否有进度提示与中断续答 |
| 结果表述 | ⚠️ | "肝郁气滞证"需翻译为用户可理解的日常语言 |
| **方剂推荐的边界** | ❌ **风险高** | 向 C 端用户直接推荐方剂（含药材与剂量）**极易越界为医疗行为**，在 FDA/MHRA 口径下几乎必然构成 claims 越界 |
| 安全拦截的用户呈现 | ⚠️ 待确认 | 命中禁忌时，是否向用户清晰说明"为什么不建议" |

**最需要改的一条**：**方剂推荐应转为"养生方向建议"，不输出具体药材剂量；或仅在 B 端（执业医师）角色下开放完整方剂。** 这与 M09 的 claims 引擎强相关——同一内容在不同法域、不同角色下的可输出范围应不同。

## 四、市场与竞品对标

**需求判断**：中国是真需求、强政策驱动，但**"辨证 + 方剂"已高度拥挤**（截至 2025-05 国内约 300 个医疗大模型）。**空白在"配伍安全 / 中西药相互作用"的工程化闭环**——这正是本板块已有的部分。

| 竞品 | 定位 | 开源 | 说明 |
|---|---|---|---|
| 问止中医大脑 | 2008 起研发，3000+ 病症、8000+ 方剂、亿级参数知识图谱 | 否 | 直营诊所，闭源，无开放 API |
| 天士力"数智本草" | 2026-05 发布，舌/面/脉多模态数十秒出报告 | 否 | 药企营销导向 |
| ShizhenGPT | 2025-09 宣称全模态且开源 | 部分是 | **代码可用性未核实** |
| ShenNong-TCM-LLM / ChatMed-TCM | 学术开源 | 是 | 成熟度低、无临床验证 |

### ⚠️ 标准硬约束（必须遵守）
**GB/T 20348-2026《中医基础理论术语》**：2026-03-31 发布、**2026-07-01 实施**，替代 2006 版，国家中医药局归口。同批实施《中医药诊断词汇 第 1 部分：舌象》《第 2 部分：脉象》《中医药临床研究质量控制规范》。
→ **证候与舌脉术语必须对齐该标准。**

## 五、可融合的开源技术

| 项目 | 许可 | 活跃度 | 能解决什么 | 集成成本 | 建议 |

| **DDInter 2.0** | 开放获取（中南大学，NAR） | 2024-09 升级 2.0 | DDI + **8359 条药物-疾病相互作用**，含机制描述与风险等级 | 中 | **建议接入**：补强中西药互作 |
| 国家级中医药多模态数据集 | 南京中医药大学 2026-05 启动 | 未知 | 四诊文本/图像/声音/视频 | — | 获取方式**未核实** |
| 国家中医药古籍数字图书馆 | 2025-05 体验版上线（八大馆） | **非开源** | 权威底本 | 低 | 作权威语料参考 |

**取舍**：
- **术语对齐 GB/T 20348-2026：必须自研**（映射表，开源无替代）。
- **证候/方剂推理：直接用开源中医 LLM + RAG，绝不自训练。**
- **十八反十九畏与妊娠禁忌：保留确定性规则表**（此处规则是正确形态，别改成模型）。
- **中西药相互作用：接 DDInter 2.0**，自研仅做"中药 → 成分 → 西药通用名"映射层。
