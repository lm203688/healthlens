# HealthLens 商业路径（修正）

**日期**：2026-11-07
**修正方向**：高净值 C 端先行（合规 gate 前置）
**版本**：v1.0（修正）
**诚实边界**：本文件是**商业路径规划**，不宣称已获客户/监管批准。任何"已有付费客户/已获批准"表述均为虚假。

---

## 0. 核心修正（一句话）

**商业化启动路径从"大众流量先"修正为"高净值 C 端先行（合规 gate 前置）"**——先用高付费意愿、对合规敏感度高的高净值客群完成**早期价值验证**，同时把合规架构（G1/G2/G3）作为**前置 gate** 建好，再向大众扩展。

---

## 1. 修正逻辑（为什么高净值先行）

| 维度 | 大众先行（原） | 高净值 C 端先行（修正后） | 理由 |
|------|--------------|------------------------|------|
| 付费意愿 | 低（免费/低价） | **高**（愿意为深度健康服务付费） | 高净值客群付费意愿强，能支撑早期合规成本 |
| 合规敏感度 | 低 | **高**（注重隐私/数据安全/服务资质） | 高净值客群对合规要求高——**倒逼合规架构先建好**（合规 gate 前置） |
| 价值验证 | 慢（需海量流量） | **快**（少而精客户深访+复购） | 高净值可做深度服务（三档精度 advanced），快速验证价值 |
| 合规成本 | 低（先跑流量） | **高（需先建合规）** | 但合规是**前置投资**，建好后大众扩展无合规风险 |
| 产品定位 | 大众（定位声明 §7） | **不变**（大众仍是目标，但启动聚焦高净值） | 定位不变，**启动路径**变——先高净值验证，再大众扩展 |

**调和说明**：定位声明 §7「非高净值专属」**仍然成立**（产品设计目标大众，高净值只是高端档）——修正的是**商业化启动路径**：不是"只做高净值"，而是"**先高净值验证 → 再大众扩展**"。

---

## 2. 合规 gate 前置（核心）

高净值 C 端先行的**前提**是合规架构（G1/G2/G3）前置建好：

1. **G1 数据合规框架**：高净值客群数据敏感（健康数据+身份信息），**必须先有数据合规框架**（PIPL/GDPR/知情同意全链路/数据使用许可）才能服务。
2. **G2 持牌终审事实化**：高净值客群要求"权威结论"——**持牌终审流程**必须文档化+事实化（AI 不终审，医师终审）。
3. **G3 医疗器械分类评估**：高净值服务若含"诊断倾向"表述，**必须先做医疗器械分类自评**——当前产品是健康评估（非诊断），自评明确边界。

**gate 语义**：合规架构三项未建 → **不启动高净值 C 端商业化**（合规 gate 前置，fail-closed）。

---

## 3. 高净值 C 端产品形态

- **核心价值**：AI 辅助健康评估 + 风险分层 + 趋势预警（八轴 A–H + 五层因果链）→ 个性化非药物方案（**三档精度**，高净值通常给全信息→advanced 档）。
- **深度服务**（高净值专属，非诊断）：
  - 完整八轴稳态画像（基因→蛋白→通路→证候→干预）
  - PRS 风险分层（**风险≠诊断**，群体相对风险，AUC 0.6–0.7）
  - 非药物个性化方案（advanced 档：AMPK/MTOR/NAD 通路精调）
  - 长期趋势追踪（可穿戴连接器 + 随访）
- **服务边界**（红线保持）：
  - **不诊断**（诊断门控默认 inactive/fail-closed）
  - **PRS 风险≠诊断**（持牌机构出具结论）
  - **不提供药物处方**（只做用药建议经持牌医师处方）
- **合规 gate**：服务前合规架构（G1/G2/G3）建好，**gate 未过不服务**。

---

## 4. 大众扩展路径（高净值验证后）

1. **价值验证**（高净值 C 端，6-12 个月）：验证八轴评估+非药物方案的**真实价值**（用户满意度/复购/健康改善反馈）。
2. **合规架构完备**（G1/G2/G3 立项清单执行）：合规专家主导，数据合规/持牌终审/器械分类自评。
3. **大众扩展**：合规完备后，三档精度（basic 免费/standard 低价/advanced 付费）面向大众——**每档可用**（抽屉组合），非全有全无。

---

## 5. 风险与边界

- **风险**：①高净值先行可能误读为"只做高净值"——**定位不变**（大众仍目标）；②高净值服务合规成本高——**前置投资**，建好后大众扩展无风险；③"权威结论"压力→**红线保持**（不诊断/PRS 风险≠诊断/持牌终审）。
- **诚实边界**：商业路径是**规划**，不宣称已获客户；合规架构（G1/G2/G3）未建前不启动商业化。
- **不宣称**：不宣称"已验证真实价值"（高净值 C 端验证未启动）；不宣称"已获监管批准"（合规架构未执行）。
