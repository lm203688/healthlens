### 实测踩到的四个坑（重要，后续勿重犯）
1. **BLAST 的 JSON2 是 ZIP 包**（PK 头），内含索引 `<RID>.json` → `{"BlastJSON":[{"File":"<RID>_1.json"}]}`，报告在 `_1.json` 的 `BlastOutput2.report`。直接 `json.loads` 必失败。
2. **PubChem 相似性搜索不能带 `/cids/`**：`/similarity/smiles/{s}/cids/JSON` 返回 400 "Search input may not be combined with any operation"。正确：`/similarity/smiles/{s}/JSON` → 202 + ListKey → `/compound/listkey/{key}/cids/JSON`。SMILES 必须整体 URL 编码。
3. **BLAST 公共队列 RTOE 不可控**：同时刻 blastn+core_nt ≈30s；**blastp+swissprot ≈34,781s（9.7 小时）**。必须 submit/status/fetch 三步异步。
4. **RCSB GraphQL 字段名写错会整体失败**（不是少一个字段）：`polymer_entity_count_nonpolymer`、`deposited_nonpolymer_entity_count` 都不存在。

### 另一个真实缺陷（已修）
`httpx.AsyncClient` 做类级共享时必须**按事件循环隔离**：跨 loop 复用会在 teardown 报 `RuntimeError: Event loop is closed`，表现为"请求成功但测试崩"。已在 `base.py::_client()` 用 `_shared_loop_id` 判定。

### 环境事实
- 本机 curl 访问 NCBI 全部 SSL 失败（exit 35），但 **Python urllib/httpx 正常**——排查网络问题时不要只用 curl 下结论。
- 本机无 Schrödinger，`/cadd/capabilities` 返回 `installed=false`，`run_job` 正确抛 `license_unavailable`。
