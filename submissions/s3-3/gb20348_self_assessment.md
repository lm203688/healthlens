## 1. 项目对齐范围

GB/T 20348-2026《中医基础理论术语》覆盖：

- 基础理论（阴阳、五行、藏象、经络、病因、病机、治则、养生）
- 术语定义、拼音、英文对照
- 术语之间的关系（包含、并列、上下位）

本项目对齐范围（**声明式，非穷尽**）：

- 八轴每一轴对应的中医概念（气化、气血、络脉、阴阳、脏腑、正邪、神、先天）
- 与西医通路的映射（AMPK-mTOR / NAD+ / 内皮微循环 / HPA / 炎症 / 自主神经 / 表观遗传）
- 古籍中的原文出处（613 条切片）
- 药物/食物干预（药食同源，300+ 条目）

## 3. 关键短板与整改计划

### 3.1 关系表达（7/15）——最高优先

**现状**：映射表 `data/axis_term_mapping.json` 只表达"轴↔术语"，未表达
"术语↔术语"的关系（包含、并列、上下位）。

**整改方案**（4-6 周）：
- 引入三元组 schema：`(subject, relation, object)`
- 关系类型起步 5 类：`contains` / `is_a` / `parallel_to` / `maps_to` / `opposes`
- 每轴补充 3-5 个国标内部关系三元组
- 前端可搜索"包含关系图"

### 3.2 术语覆盖（26/40）——中优先

**短板**：
- 经络：只覆盖"络脉"，未覆盖十二正经/奇经八脉
- 病因：六淫/七情未系统化
- 治则：多为原则性描述

**整改方案**（6-8 周）：
- 优先补齐"经络"轴：加 C 轴的十二正经子映射
- 治则：把"扶正祛邪/标本缓急"从描述升级为结构化字段
- 六淫/七情：与 F/G 轴建立子映射

### 3.3 拼音缺失（5/6）——低优先

**现状**：个别术语缺拼音（尤其中文名 → 拼音转换）。

**整改方案**（2 周）：
- 引入 `pypinyin` 自动生成
- 人工校验生僻字（如"络脉"→luò mài）

### 4.2 术语覆盖率统计脚本

`tools/gb20348_coverage.py`：

```python
def compute_coverage(term_source, mapping_file):
    """计算国标术语在 mapping 中的覆盖率"""
    gb_terms = load_gb_terms(term_source)
    mapped = load_mapping(mapping_file)
    mapped_terms = {t['term'] for t in mapped}
    coverage = len(gb_terms & mapped_terms) / len(gb_terms)
    return {
        "total_gb_terms": len(gb_terms),
        "mapped": len(gb_terms & mapped_terms),
        "coverage": round(coverage, 4),
        "missing": sorted(gb_terms - mapped_terms)
    }
```

## 5. 与国标 2.0 的潜在贡献

### 5.1 项目可作为「跨模态映射范例」

国标 2.0 若在"跨模态"（舌象/脉象/图谱）方向扩展，本项目的
"术语↔轴↔通路↔古籍"四向映射可作为跨模态术语对齐的**开源范例**，
供起草者参考。

### 5.2 项目可贡献「英文对照」

项目在每轴术语上均提供英文对照（如"气化"→"qi-transformation"、
"神"→"spirit/mind"），可为国标英译提供参考。

### 5.3 项目可贡献「古籍引用规范」

项目在古籍切片中保留 book/author/dynasty/entity 四类字段，
并标注 `needs_expert_review=true`，可推动国标制定"古籍引用规范化"章节。
