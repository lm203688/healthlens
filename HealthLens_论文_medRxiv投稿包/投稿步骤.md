# HealthLens 理论框架论文 — medRxiv 投稿包（免费、秒发 DOI、可引用）

> 目的：给你的项目增加**可引用学术背书**，且**零成本、无需期刊审稿周期**。
> 状态：稿件与元数据已就绪，仅差**你注册一个 medRxiv 账号**并完成表单（约 5 分钟）。

## 为什么先投 medRxiv（不是直接投 SCI）
- 你之前要"把理论作为论文发表、给项目增加背书"。最稳最快的背书 = **预印本 DOI**（当天可引用、Google Scholar 收录、LLM 检索可见）。
- 正式 SCIE（如 Journal of Integrative Medicine，订阅路线作者 $0）仍需同行评审 2–6 个月；预印本可先挂，评审稿后投。
- 两者不冲突：**预印本 + 期刊投稿** 是标准做法（期刊通常不禁止预印本，JIM 也不禁止）。

## 你要做的（唯一硬阻塞 = 你的账号）
1. 注册：https://www.medrxiv.org/account/register （邮箱即可，免费）
2. Submit a manuscript → primary category 选 **Medicine (General/Internal)**（secondary 填 Nutrition / Public and Global Health）
3. 上传稿件：`HealthLens_论文_整合医学稳态轴框架_全文.md`（建议用 Word/Pandoc 转 PDF 再传，排版更稳）
4. 填标题 / 作者 / 摘要 —— 直接用本目录 `submission_metadata.json` 里的字段（把 `{{YOUR_NAME}}` 等占位换成你的）
5. 勾选 **"This is a preprint, not peer-reviewed"** 与 **CC-BY**
6. 提交 → 数分钟得 DOI

## 拿到 DOI 之后（我可替你做）
- 把 `Preprint: doi:XXXX` 标注进论文首页、项目 README、GEO 长文"证据来源"块。
- 在对外材料统一口径：**"已发布预印本（medRxiv, 未经同行评审）"**，**严禁**写"已发表 SCI / 已被收录"。

## 合规红线（务必遵守）
- 全文已含去医疗化免责；切勿在投稿时改成"诊疗/疗效宣称"。
- 参考文献 DOI 已于 2026-08-16 全部核验可解析；少数文本来源标了"投稿前需全文复核"，正式投 SCI 前需补齐精确页码/卷期（不伪造）。
